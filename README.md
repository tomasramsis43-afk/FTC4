# FTC4 — نظام إدارة مركز التدريب (إعادة بناء)

إعادة بناء كاملة لـ FTC2: **نفس المعادلات المحاسبية بالضبط**، هندسة وتخزين وتصميم جديدين بالكامل، وواجهة ثنائية اللغة (عربي/إنجليزي).

## حالة المشروع
🚧 قيد البناء الأولي — التوثيق والسكيمة جاهزين، السيرفر في مرحلة الهيكلة الأساسية.

## البنية
```
server/
  migrations/001_init.sql   ← السكيمة الكاملة (تنفيذ مباشر)
  src/
    db.js                   ← اتصال Postgres (Pool + transactions)
    core-financial.js        ← معادلات مالية صرفة (num, VAT, centerIncome...)
    services/clients-service.js  ← paidTotal/remaining (بالحالة الخاصة لحوالات الشركات)
    migrate.js               ← مشغّل الـ migrations
    index.js                 ← Express app
frontend/
  i18n/ar.json, en.json      ← قواميس الترجمة (نصوص النظام فقط — بيانات المستخدم بتتخزن زي ما اتكتبت)
```

## التشغيل المحلي
```bash
cd server
npm install
cp .env.example .env    # وحط DATABASE_URL بتاعك (Neon)
npm run migrate         # ينفذ السكيمة
npm start
```

## قرارات معمارية مهمة (راجع docs/SCHEMA.md للتفصيل)
- **جداول علائقية حقيقية** بدل `kv_store` (المشكلة الأساسية في أداء FTC2)
- **نظام قيد يومي موحّد واحد** (بدل نظامين متوازيين في FTC2)
- **`transaction_kind` صريح** بدل تصنيف القروض بتحليل النص
- **الأرصدة كلها محسوبة من الحركات دايماً** (SUM)، مش أعمدة مخزَّنة — نفس فلسفة FTC2
- **ثنائية اللغة من الأساس**: كل نص نظام = مفتاح ترجمة؛ بيانات المستخدم المُدخلة تتخزن كما هي
